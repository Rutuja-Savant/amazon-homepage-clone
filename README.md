# Amazon Clone

A responsive Amazon-inspired e-commerce website built using HTML and CSS.

## Features

- Responsive navigation bar
- Search bar UI
- Product categories
- Product cards
- Promotional sections
- Responsive design
- Footer section

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Responsive Web Design
